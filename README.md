# temp-convert

A tiny command-line temperature converter written in Python. No dependencies — it
uses only the standard library.

## Usage

```
python temp_convert.py <value> <c2f|f2c>
```

- `c2f` — convert Celsius to Fahrenheit
- `f2c` — convert Fahrenheit to Celsius

## Examples

```
$ python temp_convert.py 100 c2f
100.0 C = 212.0 F

$ python temp_convert.py 32 f2c
32.0 F = 0.0 C
```
